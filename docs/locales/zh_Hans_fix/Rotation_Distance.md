# 旋转距离

Klipper 上的步进电机驱动器需要在每个
[步进电机配置部分](Config_Reference.md#stepper)中设置一个 `rotation_distance`
参数。`rotation_distance` 是指步进电机完整旋转一圈时，对应轴移动的距离。本文档描述了如何配置此值。

## 通过 steps_per_mm（或 step_distance）获取 rotation_distance

您的 3D 打印机设计者最初是根据旋转距离计算出 `steps_per_mm` 的。如果您知道 steps_per_mm，则可以使用以下通用公式来获得原始的旋转距离：
```
rotation_distance = <每转全步数> * <微步数> / <steps_per_mm>
```

或者，如果您使用的是较旧的 Klipper 配置并且知道 `step_distance` 参数，则可以使用此公式：
```
rotation_distance = <每转全步数> * <微步数> * <step_distance>
```

`<每转全步数>` 的设定取决于步进电机的类型。大多数步进电机是“1.8度步进电机”，因此每转有200个全步（360除以1.8等于200）。有些步进电机是“0.9度步进电机”，因此每转有400个全步。其他类型的步进电机较为罕见。如果不确定，请不要在配置文件中设置每转全步数，并在上述公式中使用200。

`<微步数>` 的设定由步进电机驱动器决定。大多数驱动器使用16微步。如果不确定，请在配置中设置 `microsteps: 16` 并在上述公式中使用16。

几乎所有打印机在 X、Y 和 Z 类型的轴上，`rotation_distance` 都应为整数。如果上述公式得出的旋转距离与某个整数相差在0.01以内，则将最终值四舍五入到该整数。

## 校准挤出机的 rotation_distance

对于挤出机，`rotation_distance` 是指步进电机完整旋转一圈时，耗材前进的距离。获得此设置准确值的最佳方法是使用“测量并调整”程序。

首先，为旋转距离设定一个初始估计值。这可以通过
[steps_per_mm](#obtaining-rotation_distance-from-steps_per_mm-or-step_distance)
获得，或通过[检查硬件](#extruder)获得。

然后使用以下程序进行“测量并调整”：
1. 确保挤出机内有耗材，喷嘴已加热到适当温度，打印机已准备好进行挤出。
2. 使用记号笔在距挤出机主体进料口约70mm处的耗材上做标记。然后使用数显卡尺尽可能精确地测量该标记的实际距离。记为 `<initial_mark_distance>`。
3. 使用以下命令序列挤出50mm耗材：`G91` 后跟 `G1 E50 F60`。记50mm为 `<requested_extrude_distance>`。等待挤出机完成移动（大约需要50秒）。重要的是，此测试必须使用慢速挤出速率，因为更快的速率会在挤出机内产生高压，从而影响结果。（不要使用图形前端的“挤出按钮”进行此测试，因为它们以快速率挤出。）
4. 使用数显卡尺测量挤出机主体与耗材标记之间的新距离。记为 `<subsequent_mark_distance>`。然后计算：
   `actual_extrude_distance = <initial_mark_distance> - <subsequent_mark_distance>`
5. 计算 rotation_distance：
   `rotation_distance = <previous_rotation_distance> * <actual_extrude_distance> / <requested_extrude_distance>`
   将新的 rotation_distance 四舍五入到三位小数。

如果实际挤出距离与请求挤出距离相差超过约2mm，则建议再次执行上述步骤。

注意：不要对 X、Y 或 Z 类型的轴使用“测量并调整”类型的方法进行校准。该方法对于这些轴不够精确，可能会导致配置更差。相反，如果需要，这些轴可以通过[测量皮带、皮带轮和丝杆硬件](#obtaining-rotation_distance-by-inspecting-the-hardware)来确定。

## 通过检查硬件获取 rotation_distance

通过了解步进电机和打印机运动学知识，可以计算 rotation_distance。如果不知道 steps_per_mm 或正在设计新打印机，此方法可能很有用。

### 皮带驱动轴

对于使用皮带和皮带轮的线性轴，计算旋转距离很容易。

首先确定皮带类型。大多数打印机使用2mm节距的皮带（即皮带上的每个齿相距2mm）。然后计算步进电机皮带轮上的齿数。旋转距离计算如下：
```
rotation_distance = <皮带节距> * <皮带轮齿数>
```

例如，如果打印机使用2mm皮带且皮带轮有20个齿，则旋转距离为40。

### 带丝杆的轴

使用以下公式可以轻松计算常见丝杆的旋转距离：
```
rotation_distance = <丝杆螺距> * <独立螺纹数>
```

例如，常见的“T8丝杆”的旋转距离为8（其螺距为2mm，有4个独立螺纹）。

使用“螺纹杆”的老式打印机在丝杆上只有一个“螺纹”，因此旋转距离就是螺杆的螺距。（螺距是螺杆上每个槽之间的距离。）因此，例如，M6公制螺杆的旋转距离为1，M8螺杆的旋转距离为1.25。

### 挤出机

通过测量推动耗材的“花键轴”直径并使用以下公式，可以为挤出机获得初始旋转距离：`rotation_distance = <直径> * 3.14`

如果挤出机使用齿轮，则还需要[确定并设置齿轮比](#using-a-gear_ratio)。

挤出机的实际旋转距离会因打印机而异，因为与耗材啮合的“花键轴”的抓握力会有所不同。甚至在不同耗材卷之间也会有差异。在获得初始旋转距离后，使用[测量并调整程序](#calibrating-rotation_distance-on-extruders)来获得更准确的设置。

## 使用齿轮比

设置 `gear_ratio` 可以更轻松地配置带有齿轮箱（或类似装置）的步进电机的 `rotation_distance`。大多数步进电机没有齿轮箱——如果不确定，则不要在配置中设置 `gear_ratio`。

当设置 `gear_ratio` 时，`rotation_distance` 表示齿轮箱最终齿轮完整旋转一圈时轴移动的距离。例如，如果使用“5:1”比率的齿轮箱，则可以使用[硬件知识](#obtaining-rotation_distance-by-inspecting-the-hardware)计算旋转距离，然后在配置中添加 `gear_ratio: 5:1`。

对于使用皮带和皮带轮实现的齿轮传动，可以通过计算皮带轮上的齿数来确定齿轮比。例如，如果一个16齿皮带轮的步进电机驱动一个80齿的皮带轮，则应使用 `gear_ratio: 80:16`。实际上，可以打开一个常见的现成“齿轮箱”并计算其中的齿数以确认其齿轮比。

请注意，有时齿轮箱的实际齿轮比可能与其广告宣传的略有不同。常见的BMG挤出机电机齿轮就是这种情况——它们宣传为“3:1”，但实际上使用“50:17”齿轮传动。（使用没有公因数的齿数可能改善整体齿轮磨损，因为齿在每次旋转时不会总是以相同方式啮合。）常见的“5.18:1行星齿轮箱”更准确地配置为 `gear_ratio: 57:11`。

如果轴上使用了多个齿轮，则可以在 gear_ratio 中提供逗号分隔的列表。例如，一个“5:1”齿轮箱驱动一个16齿到80齿的皮带轮可以使用 `gear_ratio: 5:1, 80:16`。

在大多数情况下，gear_ratio 应使用整数定义，因为常见的齿轮和皮带轮上的齿数是整数。然而，在皮带通过摩擦而不是齿驱动皮带轮的情况下，在齿轮比中使用浮点数可能是有意义的（例如，`gear_ratio: 107.237:16`）。
