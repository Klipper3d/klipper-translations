# 限位开关相位

本文档介绍了 Klipper 的步进电机相位调整限位开关系统。此功能可以提高传统限位开关的精度。当使用支持运行时配置的 Trinamic 步进电机驱动器时，该功能最为有用。

典型的限位开关精度约为100微米。（每次轴归零时，开关可能会稍早或稍晚触发。）尽管这是一个相对较小的误差，但它可能导致不需要的瑕疵。特别是，在打印物体的第一层时，这种位置偏差可能很明显。相比之下，典型的步进电机可以获得更高的精度。

步进电机相位调整限位机制可以利用步进电机的精度来提高限位开关的精度。步进电机通过循环一系列相位来移动，直到完成四个“全步”。因此，使用16微步的步进电机会有64个相位，当正向移动时，它会循环经过相位：0, 1, 2, ... 61, 62, 63, 0, 1, 2等。关键的是，当步进电机在直线导轨上的特定位置时，它应该始终处于相同的步进电机相位。因此，当滑块触发射限位开关时，控制该滑块的步进电机应始终处于相同的步进电机相位。Klipper 的限位开关相位系统将步进电机相位与限位开关触发相结合，以提高限位开关的精度。

为了使用此功能，必须能够识别步进电机的相位。如果使用 Trinamic TMC2130、TMC2208、TMC2224 或 TMC2660 驱动器在运行时配置模式下（即非独立模式），则 Klipper 可以从驱动器查询步进电机相位。（如果能够可靠地重置步进电机驱动器，则也可以在传统步进电机驱动器上使用此系统——详见下文细节。）

## 校准限位开关相位

如果使用带有运行时配置的 Trinamic 步进电机驱动器，则可以使用 ENDSTOP_PHASE_CALIBRATE 命令校准限位开关相位。首先，在配置文件中添加以下内容：
```
[endstop_phase]
```

然后重启打印机，运行 `G28` 命令，后跟 `ENDSTOP_PHASE_CALIBRATE` 命令。然后将工具头移动到新位置，再次运行 `G28`。尝试将工具头移动到几个不同的位置，并从每个位置重新运行 `G28`。至少运行五次 `G28` 命令。

执行上述操作后，`ENDSTOP_PHASE_CALIBRATE` 命令通常会为步进电机报告相同（或几乎相同）的相位。此相位可以保存在配置文件中，以便所有未来的 G28 命令都使用该相位。（因此，在未来的归零操作中，即使限位开关稍早或稍晚触发，Klipper 也会获得相同的位置。）

要为特定步进电机保存限位开关相位，请运行类似以下的命令：
```
ENDSTOP_PHASE_CALIBRATE STEPPER=stepper_z
```

为所有希望保存的步进电机运行上述命令。通常，在笛卡尔和 corexy 打印机上对 stepper_z 使用此功能，在 delta 打印机上对 stepper_a、stepper_b 和 stepper_c 使用此功能。最后，运行以下命令以使用数据更新配置文件：
```
SAVE_CONFIG
```

### 其他注意事项

* 此功能在 delta 打印机以及笛卡尔/corexy 打印机的 Z 限位开关上最有用。可以在笛卡尔打印机的 XY 限位开关上使用此功能，但这并不是特别有用，因为 X/Y 限位开关位置的微小误差不太可能影响打印质量。在 corexy 打印机的 XY 限位开关上使用此功能是无效的（因为在 corexy 运动学中，XY 位置不由单个步进电机决定）。在使用“probe:z_virtual_endstop” Z 限位开关的打印机上使用此功能也是无效的（因为只有当限位开关在导轨上的静态位置时，步进电机相位才稳定）。

* 在校准限位开关相位后，如果之后移动或调整了限位开关，则需要重新校准限位开关。从配置文件中删除校准数据并重新运行上述步骤。

* 为了使用此系统，限位开关必须足够精确，以在两个“全步”范围内识别步进电机位置。因此，例如，如果步进电机使用16微步且步距为0.005mm，则限位开关的精度必须至少为0.160mm。如果收到“Endstop stepper_z incorrect phase”类型的错误消息，则可能是由于限位开关不够精确。如果重新校准无济于事，则通过从配置文件中删除它们来禁用限位开关相位调整。

* 如果使用传统的由步进电机控制的 Z 轴（如笛卡尔或 corexy 打印机上）以及传统的调平螺丝，则还可以使用此系统安排每一打印层都在“全步”边界上进行。要启用此功能，请确保 G-Code 切片器配置的层高是“全步”的倍数，手动在 endstop_phase 配置部分启用 endstop_align_zero 选项（详见[配置参考](Config_Reference.md#endstop_phase)），然后重新调整调平螺丝。

* 可以在此系统中使用传统的（非Trinamic）步进电机驱动器。然而，这样做需要确保每次微控制器重置时，步进电机驱动器也重置。（如果两者总是同时重置，则Klipper可以通过跟踪其命令步进电机移动的总步数来确定步进电机相位。）目前，唯一能可靠实现此目的的方法是微控制器和步进电机驱动器仅通过USB供电，并且USB电源来自运行Raspberry Pi的主机。在这种情况下，可以指定一个mcu配置，其中包含"restart_method: rpi_usb"——该选项将安排微控制器始终通过USB电源重置，从而安排微控制器和步进电机驱动器同时重置。如果使用此机制，则需要手动配置"trigger_phase"配置部分（详见[配置参考](Config_Reference.md#endstop_phase)）。
