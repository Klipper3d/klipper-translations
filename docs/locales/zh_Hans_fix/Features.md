# 功能特性

Klipper 拥有多个引人注目的功能：

* **高精度步进电机运动**。Klipper 在计算打印机运动时会使用一个应用处理器（例如低成本的树莓派）。该应用处理器确定每个步进电机何时进行步进，将这些事件压缩后传输到微控制器，然后由微控制器在指定时间执行每个事件。每次步进事件的调度精度可达25微秒或更高。软件不使用运动学估算算法（如Bresenham算法），而是根据加速度物理特性和机器运动学物理特性精确计算步进时间。更精确的步进电机运动可提供更安静、更稳定的打印机运行。

* **行业领先的性能**。无论新旧微控制器，Klipper 都能实现高步进速率。即使是老旧的8位微控制器也能达到超过每秒17.5万步的速率。在较新的微控制器上，每秒数百万步是可能的。更高的步进速率可实现更高的打印速度。即使在高速下，步进事件的时间依然保持精确，从而提高整体稳定性。

* **支持多微控制器打印机**。例如，可以使用一个微控制器控制挤出机，另一个控制打印机加热器，第三个控制打印机其余部分。Klipper 主机软件实现了时钟同步，以补偿不同微控制器之间的时钟漂移。无需特殊代码即可启用多微控制器——只需在配置文件中添加几行额外配置即可。

* **通过简单配置文件进行配置**。更改设置时无需重新刷写微控制器。Klipper 的所有配置都存储在一个标准配置文件中，可以轻松编辑。这使得硬件的设置和维护更加容易。

* **支持“平滑压力提前”（Smooth Pressure Advance）** —— 一种用于补偿挤出机内压力效应的机制。这减少了挤出机的“渗漏”现象，并提高了打印拐角的质量。Klipper 的实现不会引入瞬间挤出速度变化，从而提高了整体稳定性和鲁棒性。

* **支持“输入整形”（Input Shaping）**，以减少振动对打印质量的影响。这可以减少甚至消除打印件中的“振纹”（也称为“重影”、“回声”或“波纹”）。它还可能允许用户在保持高质量的同时实现更快的打印速度。

* **使用“迭代求解器”** 来从简单的运动学方程精确计算步进时间。这使得将 Klipper 移植到新型机器人更容易，并且即使在复杂运动学情况下也能保持精确计时（无需“线段分割”）。

* **硬件无关性**。无论底层电子硬件如何，都能获得相同的精确时序。Klipper 微控制器代码设计为忠实地遵循主机软件提供的调度（如果无法遵循则会明显提醒用户）。这使得使用现有硬件、升级到新硬件以及对硬件保持信心变得更加容易。

* **可移植的代码**。Klipper 可在 ARM、AVR、PRU 和其他微控制器上运行。现有的“reprap”风格打印机可以在不修改硬件的情况下运行 Klipper——只需添加一个树莓派即可。Klipper 内部的代码结构也使其更容易支持其他微控制器架构。

* **更简洁的代码**。Klipper 大部分代码使用高级语言（Python）编写。运动学算法、G代码解析、加热和热敏电阻算法等均用 Python 编写。这使得开发新功能更加容易。

* **自定义可编程宏**。可在打印机配置文件中定义新的 G 代码命令（无需更改代码）。这些命令是可编程的，可以根据打印机状态产生不同的操作。

* **内置 API 服务器**。除了标准的 G 代码接口外，Klipper 还支持基于 JSON 的丰富应用程序接口。这使开发者能够构建具有详细打印机控制功能的外部应用程序。

## 其他功能

Klipper 支持许多标准3D打印机功能：

* **多种网页界面可用**。支持 Mainsail、Fluidd、OctoPrint 等。这允许使用普通网页浏览器控制打印机。运行 Klipper 的同一台树莓派也可以运行网页界面。

* **标准 G 代码支持**。支持典型“切片软件”（SuperSlicer、Cura、PrusaSlicer 等）生成的常用 G 代码指令。

* **支持多挤出机**。支持共用加热器的挤出机以及安装在独立滑架上的挤出机（IDEX）。

* **支持笛卡尔、三角洲、CoreXY、CoreXZ、混合式 CoreXY、混合式 CoreXZ、Deltesian、旋转式三角洲、极坐标和缆绳绞盘式打印机**。

* **自动调平支持**。Klipper 可配置为基础床面倾斜检测或完整网格调平。床网可根据打印尺寸进行自定义（自适应床网）。如果床面使用多个 Z 轴步进电机，Klipper 还可通过独立控制 Z 步进电机进行调平。支持大多数 Z 高度探针，包括 BL-Touch 探针和伺服激活探针。探针可校准以补偿轴扭曲。若使用“涡流探头”，则可利用快速床网扫描功能。

* **支持自动三角洲校准**。校准工具可执行基本高度校准以及增强的 X 和 Y 维度校准。校准可通过 Z 高度探针或手动探测完成。

* **运行时“排除对象”支持**。配置后，此模块可实现取消多部件打印中的某个特定对象。

* **支持常见温度传感器**（例如：常见热敏电阻、AD595、AD597、AD849x、PT100、PT1000、MAX6675、MAX31855、MAX31856、MAX31865、BME280、HTU21D、DS18B20、AHT10、SHT3x 和 LM75）。也可配置自定义热敏电阻和自定义模拟温度传感器。可监控微控制器内部温度传感器和树莓派的内部温度传感器。

* **默认启用基本热端保护**。

* **支持标准风扇、喷嘴风扇和温度控制风扇**。打印机空闲时无需保持风扇运行。对于带有转速计的风扇，可监控其转速。可为风扇分配“数学公式”以自动更新风扇速度。

* **支持运行时配置 TMC2130、TMC2208/TMC2224、TMC2209、TMC2240、TMC2660 和 TMC5160 步进电机驱动器**。还支持通过 AD5206、DAC084S085、MCP4451、MCP4728、MCP4018 和 PWM 引脚对传统步进驱动器进行电流控制。

* **支持直接连接到打印机的常见 LCD 显示屏**。也提供默认菜单。显示屏内容和菜单可通过配置文件完全自定义。

* **恒定加速度和“前瞻”支持**。所有打印机移动都会从静止状态逐渐加速到巡航速度，然后再减速至静止。传入的 G 代码移动指令流会被排队并分析——对同方向移动之间的加速度进行优化，以减少打印停顿并改善总体打印时间。

* **Klipper 实现了“步进电机相位限位开关”算法**，可提高典型限位开关的精度。适当调校后，可改善打印件第一层的床面附着力。

* **支持耗材存在传感器、耗材运动传感器和耗材宽度传感器**。

* **支持使用 adxl345、mpu9250、mpu6050、lis2dw12、lis3dh 和 icm20948 加速度计测量和记录加速度**。

* **支持限制短“之字形”移动的最高速度**，以减少打印机振动和噪音。更多信息请参见[运动学](Kinematics.md)文档。

* **为许多常见打印机提供了示例配置文件**。请查看[配置目录](../config/)获取列表。

要开始使用 Klipper，请阅读[安装](Installation.md)指南。
