# 配置检查

本文档提供了一系列步骤，以帮助确认 Klipper 的 `printer.cfg` 配置文件中的引脚设置。在完成 [安装文档](Installation.md) 中的步骤后，建议按此文档逐一检查。

在本指南中，可能需要对 Klipper 配置文件进行修改。每次修改配置文件后，务必发送 `RESTART` 命令，以确保更改生效（在 Octoprint 的终端选项卡中输入“restart”，然后点击“发送”）。每次 `RESTART` 后也建议发送 `STATUS` 命令，以验证配置文件是否成功加载。

## 验证温度

首先验证温度是否被正确报告。进入用户界面中的温度图表区域，检查喷嘴和热床（如果有的话）的温度是否显示且温度没有持续上升。如果温度在持续上升，请立即切断打印机电源。如果温度读数不准确，请检查喷嘴和/或热床的 `sensor_type` 和 `sensor_pin` 设置。

## 验证 M112 命令

进入命令控制台，在终端输入框中发送 `M112` 命令。该命令请求 Klipper 进入“关机”状态，这会导致出现错误，可通过在命令控制台中发送 `FIRMWARE_RESTART` 命令来清除该错误。Octoprint 也需要重新连接。然后再次进入温度图表区域，检查温度是否仍在更新，且温度没有上升。如果温度仍在上升，请立即切断打印机电源。

## 验证加热器

进入温度图表区域，在喷嘴/工具温度输入框中输入 50 并按回车。图表中的喷嘴温度应开始上升（大约 30 秒内）。然后从喷嘴温度下拉菜单中选择“Off”。几分钟后，温度应开始回落至初始室温值。如果温度没有上升，请检查配置文件中的 `heater_pin` 设置。

如果打印机有加热床，请对热床重复上述测试。

## 验证步进电机使能引脚

检查打印机的所有轴是否都可以手动自由移动（即步进电机已禁用）。如果不能，请发送 `M84` 命令以禁用电机。如果仍有某个轴无法自由移动，请检查对应轴的步进电机 `enable_pin` 配置。在大多数通用步进电机驱动器上，电机使能引脚为“低电平有效”，因此引脚定义前应加上 `!`（例如，`enable_pin: !PA1`）。

## 验证限位开关

手动移动打印机的所有轴，确保它们均未接触限位开关。通过命令控制台发送 `QUERY_ENDSTOPS` 命令。系统应响应所有已配置限位开关的当前状态，且所有开关状态均应为“open”（未触发）。对于每个限位开关，在手动触发该开关的同时再次运行 `QUERY_ENDSTOPS` 命令。此时，`QUERY_ENDSTOPS` 命令应报告该限位开关为“TRIGGERED”（已触发）。

如果限位开关状态显示相反（触发时报告“open”，未触发时报告“TRIGGERED”），则应在引脚定义前添加 `!`（例如，`endstop_pin: ^!PA2`），或如果已有 `!` 则将其移除。

如果限位开关状态完全没有变化，通常表示该开关连接到了错误的引脚。但也可能需要调整引脚的上拉设置（即 `endstop_pin` 名称开头的 `^` 符号——大多数打印机使用上拉电阻，因此应保留 `^` 符号）。

## 验证步进电机

使用 `STEPPER_BUZZ` 命令验证每个步进电机的连接。首先手动将指定轴移动到中间位置，然后在命令控制台中运行 `STEPPER_BUZZ STEPPER=stepper_x`。`STEPPER_BUZZ` 命令会使指定步进电机先正向移动 1 毫米，然后返回起始位置（如果 `position_endstop=0` 已定义，则每次移动开始时，电机会先远离限位开关）。此振荡动作将重复十次。

如果步进电机完全不移动，请检查该电机的 `enable_pin` 和 `step_pin` 设置。如果电机移动但无法返回原始位置，请检查 `dir_pin` 设置。如果电机振荡方向错误，通常表示该轴的 `dir_pin` 需要取反。可通过在打印机配置文件的 `dir_pin` 定义前添加 `!` 来实现（如果已有 `!` 则将其移除）。如果电机移动的距离远大于或远小于 1 毫米，请检查 `rotation_distance` 设置。

对配置文件中定义的每个步进电机重复上述测试。（将 `STEPPER_BUZZ` 命令的 `STEPPER` 参数设置为待测试的配置节名称。）如果挤出机中没有耗材，可以使用 `STEPPER_BUZZ` 命令验证挤出电机的连接（使用 `STEPPER=extruder`）。否则，最好单独测试挤出电机（见下一节）。

在验证所有限位开关和步进电机后，应测试归位机制。发送 `G28` 命令以归位所有轴。如果归位不正常，请立即切断打印机电源。如有必要，重新运行限位开关和步进电机的验证步骤。

## 验证挤出电机

测试挤出电机需要先将喷嘴加热到打印温度。进入温度图表区域，从温度下拉菜单中选择目标温度（或手动输入合适的温度）。等待打印机达到设定温度。然后进入命令控制台，点击“挤出”按钮。检查挤出电机是否按正确方向旋转。如果方向错误，请参考上一节的故障排除建议，确认挤出电机的 `enable_pin`、`step_pin` 和 `dir_pin` 设置。

## 校准 PID 参数

Klipper 支持对喷嘴和热床加热器使用 [PID 控制](https://zh.wikipedia.org/wiki/PID控制器)。要使用此控制机制，必须在每台打印机上校准 PID 参数（其他固件或示例配置文件中的 PID 参数通常效果不佳）。

要校准喷嘴的 PID 参数，请进入命令控制台并运行 `PID_CALIBRATE` 命令。例如：`PID_CALIBRATE HEATER=extruder TARGET=170`

调校测试完成后，运行 `SAVE_CONFIG` 命令以将新的 PID 参数保存到 `printer.cfg` 文件中。

如果打印机有加热床，且加热床支持 PWM（脉宽调制）控制，则建议对热床使用 PID 控制。（当热床加热器使用 PID 算法控制时，其开关频率可能高达每秒十次，不适合使用机械开关的加热器。）典型的热床 PID 校准命令为：`PID_CALIBRATE HEATER=heater_bed TARGET=60`
