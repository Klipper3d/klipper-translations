# 探针校准

本文档描述了在 Klipper 中校准“自动 Z 轴探针”X、Y 和 Z 偏移量的方法。这对于配置文件中包含 `[probe]` 或 `[bltouch]` 部分的用户非常有用。

## 校准探针 X 和 Y 偏移量

要校准 X 和 Y 偏移量，请导航到 OctoPrint 的“控制”选项卡，对打印机进行归零操作，然后使用 OctoPrint 的微调按钮将打印头移动到靠近打印床中心的位置。

在探针下方的打印床上放置一张蓝色美纹纸（或类似物品）。转到 OctoPrint 的“终端”选项卡并发送 `PROBE` 命令：
```
PROBE
```
在探针正下方的美纹纸上做一个标记（或使用其他方法记录打印床上的位置）。

执行 `GET_POSITION` 命令，并记录该命令报告的打印头 XY 位置。例如，如果看到：
```
Recv: // toolhead: X:46.500000 Y:27.000000 Z:15.000000 E:0.000000
```
则应记录探针 X 位置为 46.5，探针 Y 位置为 27。

记录探针位置后，发送一系列 G1 命令，直到喷嘴正好位于标记上方。例如，可以发送：
```
G1 F300 X57 Y30 Z15
```
将喷嘴移动到 X=57、Y=30 的位置。当找到正好位于标记上方的位置后，使用 `GET_POSITION` 命令报告该位置。此即为喷嘴位置。

X 偏移量（x_offset）为 `喷嘴_X位置 - 探针_X位置`，Y 偏移量（y_offset）同理为 `喷嘴_Y位置 - 探针_Y位置`。使用计算出的值更新 `printer.cfg` 文件，移除打印床上的胶带/标记，然后发送 `RESTART` 命令使新值生效。

## 校准探针 Z 偏移量

提供精确的探针 z_offset 对获得高质量打印至关重要。z_offset 是探针触发时喷嘴与打印床之间的距离。Klipper 的 `PROBE_CALIBRATE` 工具可用于获取该值——它将自动探针测量探针的 Z 触发位置，然后启动手动探针以获取喷嘴的 Z 高度。探针的 z_offset 将根据这些测量值计算得出。

首先对打印机归零，然后将打印头移动到靠近打印床中心的位置。进入 OctoPrint 终端选项卡并运行 `PROBE_CALIBRATE` 命令以启动该工具。

该工具将执行一次自动探针，然后抬起打印头，将喷嘴移动到探针点上方，并启动手动探针工具。如果喷嘴未移动到自动探针点的正上方，则 `ABORT`（中止）手动探针工具，并执行上述的 XY 探针偏移量校准。

手动探针工具启动后，按照[“纸张测试”](Bed_Level.md#the-paper-test)中描述的步骤，确定喷嘴与打印床在该位置的实际距离。完成这些步骤后，可以 `ACCEPT`（接受）该位置，并使用以下命令将结果保存到配置文件：
```
SAVE_CONFIG
```

请注意，如果对打印机的运动系统、热端位置或探针位置进行了更改，则会使得 `PROBE_CALIBRATE` 的结果失效。

如果探针存在 X 或 Y 偏移量，并且打印床的倾斜度发生了变化（例如通过调整床调平螺丝、运行 `DELTA_CALIBRATE`、运行 `Z_TILT_ADJUST`、运行 `QUAD_GANTRY_LEVEL` 或类似操作），则也会使 `PROBE_CALIBRATE` 的结果失效。进行上述任何调整后，都必须重新运行 `PROBE_CALIBRATE`。

如果 `PROBE_CALIBRATE` 的结果失效，则之前使用该探针获得的任何[床面网格](Bed_Mesh.md)结果也会同时失效——在重新校准探针后，必须重新运行 `BED_MESH_CALIBRATE`。

## 重复性检查

在校准探针的 X、Y 和 Z 偏移量后，最好验证探针是否能提供可重复的结果。首先对打印机归零，然后将打印头移动到靠近打印床中心的位置。进入 OctoPrint 终端选项卡并运行 `PROBE_ACCURACY` 命令。

该命令将执行十次探针测量，并产生类似以下的输出：
```
Recv: // probe accuracy: at X:0.000 Y:0.000 Z:10.000
Recv: // and read 10 times with speed of 5 mm/s
Recv: // probe at -0.003,0.005 is z=2.506948
Recv: // probe at -0.003,0.005 is z=2.519448
Recv: // probe at -0.003,0.005 is z=2.519448
Recv: // probe at -0.003,0.005 is z=2.506948
Recv: // probe at -0.003,0.005 is z=2.519448
Recv: // probe at -0.003,0.005 is z=2.519448
Recv: // probe at -0.003,0.005 is z=2.506948
Recv: // probe at -0.003,0.005 is z=2.506948
Recv: // probe at -0.003,0.005 is z=2.519448
Recv: // probe at -0.003,0.005 is z=2.506948
Recv: // probe accuracy results: maximum 2.519448, minimum 2.506948, range 0.012500, average 2.513198, median 2.513198, standard deviation 0.006250
```

理想情况下，该工具报告的最大值和最小值应完全相同。（即，探针在十次测量中均获得相同的结果。）但最大值和最小值相差一个 Z 轴“步进距离”或最多 5 微米（0.005mm）也是正常的。“步进距离”计算公式为：`rotation_distance / (full_steps_per_rotation * microsteps)`。最小值与最大值之间的差值称为“范围”（range）。因此，在上述示例中，由于打印机的 Z 轴步进距离为 0.0125，范围为 0.012500 被认为是正常的。

如果测试结果显示范围值大于 25 微米（0.025mm），则该探针的精度不足以满足典型的调平操作。可以通过调整探针速度和/或探针起始高度来提高探针的重复性。`PROBE_ACCURACY` 命令允许使用不同参数进行测试以观察其影响——详见[G代码文档](G-Codes.md#probe_accuracy)。如果探针通常能获得可重复的结果，但偶尔出现异常值，则可以通过在每次探针测量时进行多次采样来解决——详见[配置参考](Config_Reference.md#probe)中关于探针 `samples` 配置参数的说明。

如果需要新的探针速度、采样次数或其他设置，请更新 `printer.cfg` 文件并发送 `RESTART` 命令。如果进行了此类更改，最好重新[校准 z_offset](#calibrating-probe-z-offset)。如果无法获得可重复的结果，则不应使用该探针进行打印床调平。Klipper 提供了多种手动探针工具可供替代——详见[打印床调平文档](Bed_Level.md)。

## 位置偏差检查

某些探针在特定打印头位置可能存在系统性偏差，从而影响探针结果的准确性。例如，当沿 Y 轴移动时，如果探针支架轻微倾斜，则可能导致探针在不同的 Y 位置报告有偏差的结果。

这在三角洲（delta）打印机的探针上是常见问题，但也可能出现在所有类型的打印机上。

可以通过使用 `PROBE_CALIBRATE` 命令在不同的 X 和 Y 位置测量探针的 z_offset 来检查是否存在位置偏差。理想情况下，探针的 z_offset 在打印机的每个位置都应为恒定值。

对于三角洲打印机，尝试在靠近 A 塔、B 塔和 C 塔的位置分别测量 z_offset。对于笛卡尔（cartesian）、CoreXY 及类似结构的打印机，尝试在打印床四个角落附近的位置进行测量。

在开始此测试之前，首先按照本文档开头所述校准探针的 X、Y 和 Z 偏移量。然后对打印机归零，并导航到第一个 XY 位置。按照[校准探针 Z 偏移量](#calibrating-probe-z-offset)的步骤运行 `PROBE_CALIBRATE`、`TESTZ` 和 `ACCEPT` 命令，但不要运行 `SAVE_CONFIG`。记录报告的 z_offset 值。然后导航到其他 XY 位置，重复这些 `PROBE_CALIBRATE` 步骤，并记录报告的 z_offset。

如果最小报告的 z_offset 与最大报告的 z_offset 之间的差值大于 25 微米（0.025mm），则该探针不适合用于典型的调平操作。请参阅[打印床调平文档](Bed_Level.md)了解手动探针的替代方案。

## 温度偏差

许多探针在不同温度下进行探测时存在系统性偏差。例如，当探针温度较高时，可能会持续在较低的高度触发。

建议在恒定温度下运行打印床调平工具以补偿此偏差。例如，要么始终在打印机处于室温时运行这些工具，要么始终在打印机达到稳定的打印温度后运行。无论哪种情况，都建议在达到目标温度后等待几分钟，以确保打印机各部件均稳定在目标温度。

要检查是否存在温度偏差，首先让打印机处于室温状态，然后对打印机归零，将打印头移动到靠近打印床中心的位置，并运行 `PROBE_ACCURACY` 命令。记录结果。然后，在不进行归零或关闭步进电机的情况下，将打印机喷嘴和打印床加热至打印温度，再次运行 `PROBE_ACCURACY` 命令。理想情况下，两次命令应报告完全相同的结果。如果探针确实存在温度偏差，则务必始终在恒定温度下使用该探针。
