# 手动调平

本文档介绍了用于校准 Z 轴限位开关和调整调平螺丝的工具。

## 校准 Z 轴限位开关

精确的 Z 轴限位开关位置对于获得高质量打印至关重要。

但请注意，Z 轴限位开关本身的精度可能是一个限制因素。如果使用 Trinamic 步进电机驱动器，建议启用[限位开关相位](Endstop_Phase.md)检测功能，以提高开关的精度。

要进行 Z 轴限位开关校准，请先让打印机回零，然后命令打印头移动到至少高于热床 5 毫米的 Z 位置（如果尚未处于该位置），再命令打印头移动到靠近热床中心的 XY 位置，接着进入 OctoPrint 的终端选项卡并运行：
```
Z_ENDSTOP_CALIBRATE
```
然后按照["纸张测试"](Bed_Level.md#the-paper-test)中描述的步骤，确定喷嘴与热床在该位置的实际距离。完成这些步骤后，可以输入 `ACCEPT` 命令，并使用以下命令将结果保存到配置文件中：
```
SAVE_CONFIG
```

建议将 Z 轴限位开关安装在 Z 轴远离热床的一端。（远离热床回零更为可靠，因为通常这样回零总是安全的。）但是，如果必须朝向热床回零，建议调整限位开关，使其在略高于热床的位置（例如 0.5mm）触发。几乎所有限位开关都可以在触发点之后安全地再压入一小段距离。这样做后，会发现 `Z_ENDSTOP_CALIBRATE` 命令报告的 Z 轴 position_endstop 值为一个较小的正值（例如 0.5mm）。在距离热床还有一段距离时就触发限位开关，可以降低意外撞击热床的风险。

一些打印机可以手动调整物理限位开关的位置。但建议使用 Klipper 通过软件进行 Z 轴限位开关定位——一旦物理限位开关的位置调整到方便的位置，就可以通过运行 `Z_ENDSTOP_CALIBRATE` 命令或手动更新配置文件中的 Z 轴 position_endstop 值来进行后续的任何调整。

## 调整调平螺丝

使用调平螺丝获得良好热床调平的关键在于，在调平过程中利用打印机的高精度运动系统。具体做法是：命令喷嘴移动到每个调平螺丝附近的 XY 位置，然后调整该螺丝，直到热床与喷嘴之间达到设定的距离。Klipper 提供了一个工具来协助完成此操作。要使用该工具，必须先指定每个螺丝的 XY 位置。

这需要创建一个 `[bed_screws]` 配置部分。例如，可能看起来像这样：
```
[bed_screws]
screw1: 100, 50
screw2: 100, 150
screw3: 150, 100
```

如果调平螺丝位于热床下方，则直接指定螺丝正上方的 XY 位置。如果螺丝位于热床外部，则指定一个最靠近螺丝但仍处于热床范围内的 XY 位置。

配置文件准备就绪后，运行 `RESTART` 命令加载该配置，然后通过运行以下命令启动工具：
```
BED_SCREWS_ADJUST
```

该工具会将打印机的喷嘴移动到每个螺丝的 XY 位置，然后将喷嘴移动到 Z=0 的高度。此时，可以使用“纸张测试”来调整位于喷嘴正下方的调平螺丝。参见["纸张测试"](Bed_Level.md#the-paper-test)中的说明，但这次是调整调平螺丝，而不是命令喷嘴移动到不同的高度。调整调平螺丝，直到来回推动纸张时能感觉到轻微的摩擦力。

当调整螺丝到能感觉到轻微摩擦力时，运行 `ACCEPT` 或 `ADJUSTED` 命令。如果调平螺丝需要调整（通常螺丝转动超过约 1/8 圈），请使用 `ADJUSTED` 命令。如果无需进行显著调整，则使用 `ACCEPT` 命令。这两个命令都会使工具进入下一个螺丝的调整。 （当使用 `ADJUSTED` 命令时，工具会安排进行额外一轮的调平螺丝调整；当所有调平螺丝都被验证无需显著调整时，工具才算成功完成。）可以使用 `ABORT` 命令提前退出工具。

当打印机具有平坦的打印表面（如玻璃）和笔直的导轨时，此系统效果最佳。成功完成热床调平工具后，热床即可准备打印。

### 精细调平螺丝调整

如果打印机使用三个调平螺丝，且所有三个螺丝都在热床下方，则可能可以进行第二步“高精度”热床调平。这是通过命令喷嘴移动到每个调平螺丝调整时热床移动距离更大的位置来实现的。

例如，考虑一个在 A、B 和 C 位置有螺丝的热床：

[bed_screws](img/bed_screws.svg.png)

对于在 C 位置对调平螺丝进行的每次调整，热床将围绕其余两个调平螺丝定义的支点（此处显示为绿线）摆动。在这种情况下，对 C 位置的调平螺丝进行的每次调整，都会使 D 位置的热床移动距离比在 C 位置直接调整时更大。因此，当喷嘴位于 D 位置时，可以对 C 螺丝进行更精确的调整。

要启用此功能，需要确定额外的喷嘴坐标并将其添加到配置文件中。例如，可能看起来像这样：
```
[bed_screws]
screw1: 100, 50
screw1_fine_adjust: 0, 0
screw2: 100, 150
screw2_fine_adjust: 300, 300
screw3: 150, 100
screw3_fine_adjust: 0, 100
```

启用此功能后，`BED_SCREWS_ADJUST` 工具将首先提示在每个螺丝正上方进行粗调，一旦这些调整被接受，它将提示在额外的位置进行精细调整。在每个位置继续使用 `ACCEPT` 和 `ADJUSTED` 命令。

## 使用热床探针调整调平螺丝

这是另一种使用热床探针校准热床水平的方法。要使用此功能，必须拥有一个 Z 轴探针（如 BL Touch、电感式传感器等）。

要启用此功能，需要确定喷嘴的坐标，使得 Z 轴探针位于螺丝上方，然后将其添加到配置文件中。例如，可能看起来像这样：

```
[screws_tilt_adjust]
screw1: -5, 30
screw1_name: front left screw
screw2: 155, 30
screw2_name: front right screw
screw3: 155, 190
screw3_name: rear right screw
screw4: -5, 190
screw4_name: rear left screw
horizontal_move_z: 10.
speed: 50.
screw_thread: CW-M3
```

screw1 始终是其他螺丝的参考点，因此系统假设 screw1 的高度是正确的。始终先运行 `G28`，然后运行 `SCREWS_TILT_CALCULATE` —— 它应产生类似以下的输出：
```
Send: G28
Recv: ok
Send: SCREWS_TILT_CALCULATE
Recv: // 01:20 表示 1 圈加 20 分钟，CW=顺时针，CCW=逆时针
Recv: // front left screw (base) : x=-5.0, y=30.0, z=2.48750
Recv: // front right screw : x=155.0, y=30.0, z=2.36000 : adjust CW 01:15
Recv: // rear right screw : y=155.0, y=190.0, z=2.71500 : adjust CCW 00:50
Recv: // read left screw : x=-5.0, y=190.0, z=2.47250 : adjust CW 00:02
Recv: ok
```

这意味着：
- 左前螺丝是参考点，你不能更改它。
- 右前螺丝必须顺时针旋转 1 圈加四分之一圈
- 右后螺丝必须逆时针旋转 50 分钟
- 左后螺丝必须顺时针旋转 2 分钟（不需要调整，很好）

请注意，“分钟”指的是“时钟表盘上的分钟”。例如，15 分钟就是完整一圈的四分之一。

重复此过程数次，直到获得良好的热床水平——通常当所有调整都低于 6 分钟时即可。

如果探针安装在热端侧面（即具有 X 或 Y 偏移），请注意，调整热床倾斜度会使之前在热床倾斜时进行的任何探针校准失效。在调整完调平螺丝后，务必运行[探针校准](Probe_Calibrate.md)。

当使用保存的热床网格时，`MAX_DEVIATION` 参数非常有用，可确保热床水平度没有偏离网格创建时的位置太远。例如，可以在切片软件的自定义启动 G 代码中，在加载网格之前添加 `SCREWS_TILT_CALCULATE MAX_DEVIATION=0.01`。如果超出配置的限制（本例中为 0.01mm），它将中止打印，让用户有机会调整螺丝并重新开始打印。

如果调平螺丝只能朝一个方向旋转，`DIRECTION` 参数会很有用。例如，螺丝可能从最低（或最高）可能位置开始拧紧，只能朝一个方向旋转以抬高（或降低）热床。如果只能顺时针旋转螺丝，请运行 `SCREWS_TILT_CALCULATE DIRECTION=CW`。如果只能逆时针旋转，请运行 `SCREWS_TILT_CALCULATE DIRECTION=CCW`。系统会选择一个合适的参考点，使得所有螺丝都可以朝给定方向旋转来调平热床。
