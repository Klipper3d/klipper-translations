# 平台调平

平台调平（有时也称为“平台校准”）对于获得高质量的打印至关重要。如果平台没有正确“调平”，可能会导致不良的床附着力、“翘曲”以及整个打印过程中出现微妙的问题。本文档作为在Klipper中执行平台调平的指南。

理解平台调平的目标很重要。如果在打印期间打印机被命令到位置`X0 Y0 Z10`，那么目标就是让打印机喷嘴与打印机平台之间的距离精确为10毫米。进一步地，当打印机随后被命令到位置`X50 Z10`时，目标是在整个水平移动过程中保持喷嘴与平台之间的距离为10毫米。

为了获得高质量的打印，打印机应该被校准，使Z方向的距离精度达到约25微米（.025mm）。这是一个很小的距离——显著小于典型人类头发的宽度。这个尺度无法用肉眼测量。细微的影响（如热膨胀）会影响该尺度上的测量。获得高精度的关键在于使用可重复的过程，并利用打印机自身运动系统的高精度进行调平。

## 选择合适的校准机制

不同类型的打印机使用不同的方法进行平台调平。所有这些最终都依赖于“纸张测试”（如下所述）。然而，特定类型打印机的实际过程在其他文档中有描述。

在运行任何这些校准工具之前，请务必运行[配置检查文档](Config_checks.md)中描述的检查。在执行平台调平之前，需要验证基本的打印机运动。

对于带有“自动Z探针”的打印机，请确保按照[探针校准](Probe_Calibrate.md)文档中的指示校准探针。对于三角洲打印机，请参阅[三角洲校准](Delta_Calibrate.md)文档。对于带床螺丝和传统Z限位开关的打印机，请参阅[手动调平](Manual_Level.md)文档。

在校准过程中，可能需要将打印机的Z `position_min`设置为负数（例如，`position_min = -2`）。即使在校准例程期间，打印机也会强制边界检查。设置一个负数允许打印机移动到低于平台名义位置的位置，这在尝试确定实际床位置时可能会有所帮助。

## “纸张测试”

主要的床校准机制是“纸张测试”。它包括在打印机的床和喷嘴之间放置一张普通的“复印机纸”，然后命令喷嘴到不同的Z高度，直到推动纸张来回移动时感觉到少量摩擦力。

即使拥有“自动Z探针”，理解“纸张测试”也很重要。探针本身通常需要校准才能获得良好的结果。该探针校准是使用这种“纸张测试”完成的。

为了进行纸张测试，用剪刀裁剪一小块矩形纸张（例如，5x3厘米）。纸张通常厚度约为100微米（0.100mm）。（纸张的确切厚度并不关键。）

纸张测试的第一步是检查打印机的喷嘴和床。确保喷嘴或床上没有塑料（或其他碎屑）。

**检查喷嘴和床以确保没有塑料！**

如果总是使用特定的胶带或打印表面进行打印，则可以在该胶带/表面就位的情况下进行纸张测试。但是，请注意，胶带本身具有厚度，不同的胶带（或任何其他打印表面）都会影响Z测量。确保重新运行纸张测试以测量每种使用的表面。

如果有塑料在喷嘴上，加热挤出机并用金属镊子移除塑料。等待挤出机完全冷却至室温后再继续进行纸张测试。在喷嘴冷却的同时，用金属镊子移除任何可能渗出的塑料。

**始终在喷嘴和床均为室温时进行纸张测试！**

当喷嘴加热时，其相对于床的位置由于热膨胀而改变。这种热膨胀通常约为100微米，大约相当于一张典型打印纸的厚度。热膨胀的确切量并不关键，正如纸张的确切厚度也不关键。假设两者相等开始（见下文关于确定两者之间差异的方法）。

似乎有些奇怪，在目标是获得加热时一致的距离时，在室温下调准距离。然而，如果在喷嘴加热时进行校准，往往会向纸上施加少量熔融塑料，这改变了感受到的摩擦量。这使得很难获得良好的校准。在床/喷嘴热的时候校准还大大增加了烫伤的风险。热膨胀的量是稳定的，因此可以在以后的校准过程中轻松解决。

**使用自动化工具确定精确的Z高度！**

Klipper有几个可用的帮助脚本（例如，MANUAL_PROBE、Z_ENDSTOP_CALIBRATE、PROBE_CALIBRATE、DELTA_CALIBRATE）。请参阅上述[描述](#choose-the-appropriate-calibration-mechanism)的文档来选择其中之一。

在OctoPrint终端窗口中运行相应的命令。脚本将在OctoPrint终端输出中提示用户交互。它看起来像这样：
```
Recv: // Starting manual Z probe. Use TESTZ to adjust position.
Recv: // Finish with ACCEPT or ABORT command.
Recv: // Z position: ?????? --> 5.000 <-- ??????
```

当前喷嘴的高度（根据打印机当前的理解）显示在"-->"和"<--"之间。右侧的数字是上次探测尝试大于当前高度的高度，左侧是上次探测尝试小于当前高度的高度（如果没有尝试过则为"??????"）。

将纸张放在喷嘴和床之间。折叠纸张的一个角以便更容易抓住可能是有用的。（尽量避免在前后移动纸张时向下压床。）

使用TESTZ命令请求喷嘴更靠近纸张。例如：
```
TESTZ Z=-.1
```

TESTZ命令会从喷嘴当前位置相对移动一定距离。（因此，`Z=-.1`请求喷嘴朝床方向移动0.1毫米。）喷嘴停止移动后，前后移动纸张检查喷嘴是否接触纸张以及感受的摩擦量。继续发出TESTZ命令，直到在测试纸张时感到少量摩擦为止。

如果发现过多的摩擦，可以使用正Z值将喷嘴向上移动。也可以使用`TESTZ Z=+`或`TESTZ Z=-`来“二分”最后一个位置——即移动到两个位置之间的中间位置。例如，如果从TESTZ命令收到以下提示：
```
Recv: // Z position: 0.130 --> 0.230 <-- 0.280
```
然后，`TESTZ Z=-`会将喷嘴移动到Z位置0.180（介于0.130和0.230之间）。可以使用此功能快速缩小到一致的摩擦。还可以使用`Z=++`和`Z=--`直接返回过去的测量值——例如，在上述提示后，`TESTZ Z=--`命令会将喷嘴移动到Z位置0.130。

找到少量摩擦后，运行ACCEPT命令：
```
ACCEPT
```
这将接受给定的Z高度并继续使用给定的校准工具。

感受到的确切摩擦量并不关键，就像热膨胀的确切量和纸张的确切宽度并不关键一样。只需每次运行测试时尝试获得相同的摩擦量即可。

如果在测试期间出现问题，可以使用`ABORT`命令退出校准工具。

## 确定热膨胀

成功进行平台调平后，可以进一步计算“热膨胀”、“纸张厚度”和“纸张测试期间感受到的摩擦量”的综合影响。

这类计算通常不需要，因为大多数用户发现简单的“纸张测试”提供了良好的结果。

进行此计算最简单的方法是打印一个在所有侧面都有直壁的测试对象。可以使用[docs/prints/square.stl](prints/square.stl)中的大空心方形。在切片对象时，确保切片器对第一层使用与后续各层相同的层高和挤压宽度。使用粗略的层高（层高应约为喷嘴直径的75%），并且不要使用边缘或底座。

打印测试对象，等待其冷却并从床上取下。检查对象的最低层。（沿着底部边缘用手指或指甲滑动也可能有用。）如果发现底层稍微沿物体的所有边突出，则表明喷嘴略微接近床面。可以发出`SET_GCODE_OFFSET Z=+.010`命令增加高度。在后续打印中可以检查此行为并根据需要进行进一步调整。此类调整通常为几十微米（.010mm）。

如果底层始终比后续层窄，则可以使用SET_GCODE_OFFSET命令进行负Z调整。如果不确定，可以减少Z调整，直到打印的底层出现小突起，然后回退直到突起消失。

应用所需的Z调整最简单的方法是创建一个START_PRINT g-code宏，安排切片器在每次打印开始时调用该宏，并向该宏添加一个SET_GCODE_OFFSET命令。有关详细信息，请参阅[切片软件](Slicers.md)文档。
