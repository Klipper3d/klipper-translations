# 示例配置

本文档包含向Klipper github仓库（位于[config目录](../config/)）贡献示例Klipper配置的指南。

请注意，[Klipper社区Discourse服务器](https://community.klipper3d.org)也是查找和共享配置文件的有用资源。

## 指南

1. 选择适当的配置文件名前缀：
   1. `printer`前缀用于主流制造商销售的原装打印机。
   2. `generic`前缀用于可能在多种不同类型打印机中使用的3D打印机主板。
   3. `kit`前缀用于根据广泛使用的规范组装的3D打印机。这些“套件”打印机通常与普通的“打印机”不同，因为它们不是由制造商销售的。
   4. `sample`前缀用于可以复制粘贴到主配置文件中的配置“片段”。
   5. `example`前缀用于描述打印机运动学。这种类型的配置通常仅在添加新类型打印机运动学代码时才添加。
2. 所有配置文件必须以`.cfg`后缀结尾。`printer`配置文件必须以年份结尾，后跟`.cfg`（例如，`-2019.cfg`）。在这种情况下，年份是给定打印机大约销售的年份。
3. 在配置文件名中不要使用空格或特殊字符。文件名应仅包含字符`A-Z`、`a-z`、`0-9`、`-`和`.`。
4. Klipper必须能够启动`printer`、`generic`和`kit`示例配置文件而不出现错误。这些配置文件应添加到[测试/klippy/printers.test](../test/klippy/printers.test)回归测试用例中。将新配置文件添加到该测试用例的适当部分，并在该部分内按字母顺序排列。
5. 示例配置应针对打印机的“原装”配置。（在主Klipper仓库中跟踪太多“自定义”配置是不现实的。）同样，我们只为具有主流流行度的打印机、套件和主板添加示例配置文件（例如，至少有100台在积极使用）。考虑使用[Klipper社区Discourse服务器](https://community.klipper3d.org)来处理其他配置。
6. 仅指定给定打印机或主板上存在的设备。不要指定特定于您特定设置的设置。
   1. 对于`generic`配置文件，应仅描述主板上的设备。例如，在“generic”配置中添加显示配置部分是没有意义的，因为无法知道该板是否会连接到该类型的显示器。如果板子有特定的硬件端口来支持可选外设（例如，bltouch端口），则可以为给定设备添加一个“注释掉”的配置部分。
   2. 不要在示例配置中指定`pressure_advance`，因为该值是特定于耗材的，而不是打印机硬件。同样，不要指定`max_extrude_only_velocity`和`max_extrude_only_accel`设置。
   3. 不要指定包含主机路径或主机硬件的配置部分。例如，不要指定`[virtual_sdcard]`或`[temperature_host]`配置部分。
   4. 仅定义利用给定打印机特定功能或定义通常由为给定打印机配置的切片软件发出的g代码的宏。
7. 在可能的情况下，最好使用与现有配置文件相同的措辞、短语、缩进和部分顺序。
   1. 每个配置文件的顶部应列出用户在“make menuconfig”期间应选择的微控制器类型。它还应包含对“docs/Config_Reference.md”的引用。
   2. 不要将字段文档复制到示例配置文件中。（这样做会增加维护负担，因为更新文档需要在许多地方进行更改。）
   3. 示例配置文件不应包含“SAVE_CONFIG”部分。如有必要，从SAVE_CONFIG部分复制相关字段到主配置区域的适当部分。
   4. 使用`field: value`语法而不是`field=value`。
   5. 添加挤出机`rotation_distance`时，如果挤出机有齿轮机构，最好指定`gear_ratio`。我们期望示例配置中的rotation_distance与挤出机中齿轮的周长相关联 - 通常在20到35mm范围内。指定`gear_ratio`时，最好指定机构上的实际齿轮（例如，优先使用`gear_ratio: 80:20`而不是`gear_ratio: 4:1`）。有关更多信息，请参阅[旋转距离文档](Rotation_Distance.md#using-a-gear_ratio)。
   6. 避免定义设置为其默认值的字段值。例如，不应指定`min_extrude_temp: 170`，因为这已经是默认值。
   7. 在可能的情况下，行不应超过80列。
   8. 避免在配置文件中添加署名或修订消息。（例如，避免添加像“此文件由...创建”的行。）在git提交消息中放置署名和更改历史。
8. 不要在示例配置文件中使用任何已弃用的功能。
9. 不要在示例配置文件中禁用默认的安全系统。例如，配置不应指定自定义的`max_extrude_cross_section`。不要启用调试功能。例如，不应有`force_move`配置部分。
10. Klipper支持的所有已知板子都可以使用默认的串行波特率250000。不要在示例配置文件中推荐不同的波特率。

示例配置文件通过创建github“拉取请求”提交。请也遵循[贡献文档](CONTRIBUTING.md)中的说明。
