# 压力提前（Pressure Advance）

本文档提供有关为特定喷嘴和耗材调整“压力提前”配置变量的信息。压力提前功能有助于减少渗料（ooze）。有关压力提前如何实现的更多信息，请参阅[运动学](Kinematics.md)文档。

## 调整压力提前

压力提前有两个有用的功能——它可以在非挤出移动期间减少渗料，并在拐角处减少拉丝或凸起（blobbing）。本指南使用第二个功能（减少拐角处的凸起）作为调校机制。

要校准压力提前，打印机必须已配置并正常运行，因为调校测试涉及打印和检查测试模型。在运行测试之前，最好先完整阅读本文档。

使用切片软件为[docs/prints/square_tower.stl](prints/square_tower.stl)中的大型空心方块生成 G 代码。使用高速（例如 100mm/s）、零填充和较粗的层高（层高应约为喷嘴直径的 75%）。确保在切片软件中禁用任何“动态加速度控制”和“斜接缝”（scarf joint）功能。

通过发出以下 G 代码命令来准备测试：
```
SET_VELOCITY_LIMIT SQUARE_CORNER_VELOCITY=1 ACCEL=500
```
此命令使喷嘴在拐角处移动得更慢，以突出挤出机压力的效果。然后，对于直驱挤出机，运行命令：
```
TUNING_TOWER COMMAND=SET_PRESSURE_ADVANCE PARAMETER=ADVANCE START=0 FACTOR=.005
```
对于长皮带（Bowden）挤出机，请使用：
```
TUNING_TOWER COMMAND=SET_PRESSURE_ADVANCE PARAMETER=ADVANCE START=0 FACTOR=.020
```
然后打印该模型。打印完成后，测试打印件看起来像这样：

[tuning_tower](img/tuning_tower.jpg)

上述 `TUNING_TOWER` 命令指示 Klipper 在打印的每一层更改 `pressure_advance` 设置。打印件的较高层将设置更大的压力提前值。低于理想 `pressure_advance` 设置的层在拐角处会有凸起，而高于理想设置的层可能导致拐角变圆或在接近拐角前挤出不良。

如果观察到拐角打印质量变差，可以提前取消打印（从而避免打印已知高于理想 `pressure_advance` 值的层）。

检查打印件，然后使用数显卡尺找到拐角质量最佳的高度。如有疑问，优先选择较低的高度。

[tune_pa](img/tune_pa.jpg)

然后可以计算 `pressure_advance` 值：`pressure_advance = <起始值> + <测量高度> * <系数>`。（例如，`0 + 12.90 * .020` 的结果为 `.258`。）

如果自定义 `START` 和 `FACTOR` 的设置有助于确定最佳压力提前值，也可以这样做。进行此操作时，务必在每次测试打印开始时发出 `TUNING_TOWER` 命令。

典型的压力提前值在 0.050 到 1.000 之间（高端值通常仅用于皮带挤出机）。如果压力提前值高达 1.000 时仍无明显改善，则压力提前不太可能提高打印质量。此时应恢复到默认配置并禁用压力提前。

尽管此调校练习直接改善了拐角质量，但请记住，良好的压力提前配置还能在整个打印过程中减少渗料。

完成此测试后，在配置文件的 `[extruder]` 部分设置 `pressure_advance = <计算值>`，并发出 `RESTART` 命令。`RESTART` 命令将清除测试状态，并将加速度和拐角速度恢复到正常值。

## 重要提示

* 压力提前值取决于挤出机、喷嘴和耗材。不同制造商或不同颜料的耗材通常需要显著不同的压力提前值。因此，应在每台打印机上以及使用每卷耗材时校准压力提前。

* 打印温度和挤出速率会影响压力提前。在调整压力提前之前，务必先校准[挤出机旋转距离](Rotation_Distance.md#calibrating-rotation_distance-on-extruders)和[喷嘴温度](http://reprap.org/wiki/Triffid_Hunter%27s_Calibration_Guide#Nozzle_Temperature)。

* 测试打印设计为在高挤出机流速下运行，但其他切片设置保持“正常”。通过使用高打印速度（例如 100mm/s）和粗层高（通常约为喷嘴直径的 75%）来获得高流速。其他切片设置应与默认值相似（例如，2 或 3 条外轮廓线，正常的回抽量）。将外轮廓速度设置为与其他打印部分相同的速度可能有用，但不是必需的。

* 测试打印在每个拐角处表现出不同行为是很常见的。切片软件通常会在一个拐角处安排换层，这可能导致该拐角与其他三个拐角显著不同。如果发生这种情况，请忽略该拐角，并使用其他三个拐角来调整压力提前。其余拐角略有差异也很常见。（这可能是由于打印机框架在某些方向拐角时反应的微小差异所致。）尽量选择一个对所有剩余拐角都有效的值。如有疑问，优先选择较低的压力提前值。

* 如果使用高压力提前值（例如，超过 0.200），可能会发现在恢复打印机正常加速度时挤出机出现打滑。压力提前系统通过在加速期间额外推送耗材并在减速期间回抽该耗材来补偿压力。在高加速度和高压力提前的情况下，挤出机可能没有足够的扭矩来推送所需的耗材。如果发生这种情况，请使用较低的加速度值或禁用压力提前。

* 一旦在 Klipper 中调校好压力提前，可能仍然有用在切片软件中配置一个较小的回抽值（例如 0.75mm），并利用切片软件的“回抽擦拭”（wipe on retract）选项（如果可用）。这些切片设置可能有助于抵消由耗材内聚力（塑料粘性导致耗材被拉出喷嘴）引起的渗料。建议禁用切片软件的“回抽时 Z 轴抬升”（z-lift on retract）选项。

* 压力提前系统不会改变刀头的时序或路径。启用压力提前的打印与禁用压力提前的打印所需时间相同。压力提前也不会改变打印过程中挤出的总耗材量。压力提前会导致在移动加速和减速期间产生额外的挤出机运动。非常高的压力提前设置会导致在加速和减速期间产生大量的挤出机运动，且没有任何配置设置限制该运动量。
