# 称重传感器

本文档介绍了 Klipper 对称重传感器（load cell）的支持。基本的称重传感器功能可用于读取力数据，以及称量如耗材等物品。一个经过校准的力传感器是基于称重传感器探针的重要组成部分。

## 使用 `LOAD_CELL_DIAGNOSTIC`

首次连接称重传感器时，建议运行 `LOAD_CELL_DIAGNOSTIC` 来检查是否存在问题。该工具会从称重传感器收集 10 秒的数据并报告统计信息：

```
$ LOAD_CELL_DIAGNOSTIC
// 正在收集称重传感器数据，持续 10 秒...
// 采集的样本数：3211
// 测得的每秒样本数：332.0
// 有效样本：3211，饱和样本：0，唯一值：900
// 样本范围：[4.01% 至 4.02%]
// 样本范围 / 传感器量程：0.00524%
```

你可以通过这些数据检查以下内容：

* 传感器的配置采样率应接近“测得的每秒样本数”值。如果不接近，则可能存在配置或接线问题。
* “饱和样本”应为 0。如果存在饱和样本，意味着称重传感器承受的力超过了其测量范围。
* “唯一值”应占“采集的样本数”的较大比例。如果“唯一值”为 1，则极有可能存在接线问题。
* 在运行 `LOAD_CELL_DIAGNOSTIC` 时轻敲或按压传感器。如果一切正常，这应会增加“样本范围”。

## 校准称重传感器

称重传感器使用 `LOAD_CELL_CALIBRATE` 命令进行校准。这是一个交互式校准工具，引导你完成三步过程：

1. 首先使用 `TARE` 命令建立零力值。这对应配置值 `reference_tare_counts`。
2. 接着，在称重传感器上施加一个已知的负载或力，并运行 `CALIBRATE GRAMS=nnn` 命令。由此计算出 `counts_per_gram` 值。有关如何操作的建议，请参见[下一节](#applying-a-known-force-or-load)。
3. 最后，使用 `ACCEPT` 命令保存结果。

你可以随时使用 `ABORT` 取消校准过程。

### 施加一个已知的力或负载

`CALIBRATE GRAMS=nnn` 步骤可以通过多种方式完成。如果你的称重传感器位于平台（如热床或耗材架）下方，最简单的方法是在平台上放置一个已知质量的物体。例如，你可以使用几个 1KG 的耗材卷轴。

如果你的称重传感器位于打印机的喷头中，则采用不同的方法更为简便。将数字秤放在打印机的热床上，然后轻轻将喷头下压到秤上（或者如果热床可移动，则将热床上升至喷头）。你可以尝试使用 `FORCE_MOVE` 命令来完成此操作。但更可能的情况是，你需要在电机关闭的情况下手动移动 Z 轴，直到喷头压在秤上。

理想的校准力应占称重传感器额定容量的较大比例。例如，如果你有一个 5Kg 的称重传感器，理想情况下应用 5kg 的质量进行校准。这对于需要承受大量重量的床下传感器可能效果很好。但对于喷头探针，这种负载可能会损坏你的打印机热床或喷头。请尽量使用至少 1Kg 的力，大多数打印机应能承受而不会出现问题。

校准时请仔细记录报告的值：

```
$ CALIBRATE GRAMS=555
// 校准值：-2.78% (-59803108)，计数/克：73039.78739，总容量：± 29.14Kg
```

`总容量` 应接近基于传感器容量的称重传感器理论额定值。如果大得多，你可能在传感器中使用了更高的增益设置或更灵敏的称重传感器。对于 32 位和 24 位传感器来说，这不那么关键，但对于低比特宽度的传感器则更为关键。

## 读取力数据
力数据可以通过 GCode 命令读取：

```
LOAD_CELL_READ
// 10.6g (1.94%)
```

数据也会被持续读取，并可在宏中通过 `load_cell` 打印机对象获取：

```
{% set grams = printer.load_cell.force_g %}
```

这提供过去 1 秒的平均力，类似于温度传感器的工作方式。

## 称重传感器去皮
去皮（有时称为归零）将称重传感器当前报告的重量设置为 0。这对于相对于已知重量进行测量很有用。例如，在测量耗材卷轴时，使用 `LOAD_CELL_TARE` 将重量设置为 0。然后，随着耗材的打印，称重传感器将报告已使用的耗材重量。

```
LOAD_CELL_TARE
// 称重传感器去皮值：5.32% (445903)
```

当前去皮值会在打印机状态中报告，并可在宏中读取：

```
{% set tare_counts = printer.load_cell.tare_counts %}
```

## 称重传感器探针安全性

由于称重传感器是直接接触喷嘴的探针，因此如果使用过大的力，可能会损坏你的打印机。称重传感器探测系统包含多项安全检查，旨在防止对喷头施加过大的力。了解这些检查及其工作原理非常重要，因为通过选择不当的配置值，你可能会使大多数检查失效。

#### 校准检查
每次开始归位移动时，`load_cell_probe` 都会检查称重传感器是否已校准。如果未校准，它将停止移动并报错：`!! 称重传感器未校准`。

#### `counts_per_gram`
此设置用于将原始传感器计数转换为克。所有安全限制都以克为单位，方便使用。如果 `counts_per_gram` 设置不准确，你很容易超过喷头的安全力。你绝不应猜测此值。使用 `LOAD_CELL_CALIBRATE` 来找到你称重传感器的实际 `counts_per_gram`。

#### `trigger_force`
这是触发力（以克为单位），当触发限位开关时会停止归位移动。当归位移动开始时，限位开关会使用称重传感器的当前读数进行去皮。`trigger_force` 是从该去皮值开始测量的。当探针与热床碰撞时，此值总会有一些超调，因此请保守设置。例如，100g 的设置可能会导致喷头停止前峰值力达到 350g。这种超调会随着更快的探测 `速度`、较低的 ADC 采样率或 [多 MCU 归位](Multi_MCU_Homing.md) 而增加。

#### `reference_tare_counts`
这是由 `LOAD_CELL_CALIBRATE` 设置的基准去皮值。该值与 `force_safety_limit` 配合使用，以限制归位或探测时喷头的最大力。

#### `force_safety_limit`
这是探针在归位或探测时允许的相对于 `reference_tare_counts` 的最大绝对力。如果 MCU 检测到此力被超过，它将关闭打印机并报错 `!! 称重传感器限位开关：力过大！`。有多种情况可能触发此错误：

此保护措施防范的第一个风险是为 `drift_filter_cutoff_frequency` 选择了过大的值。这可能导致漂移滤波器过滤掉探测事件并继续归位移动。如果发生这种情况，`force_safety_limit` 将作为备用保护。

第二个问题是反复在同一个位置探测。Klipper 在执行单个 `PROBE` 命令时不会收回探针。这可能导致在探测周期结束时对喷头施加力。由于外部力在不同探测位置之间可能有很大差异，`load_cell_probe` 在每次探测开始前都会进行去皮。如果你重复 `PROBE` 命令，`load_cell_probe` 将在当前力下对限位开关进行去皮。多次循环会导致喷头上的力不断增加。`force_safety_limit` 会阻止此循环失控。

这种失控的另一种情况是应变片损坏。如果金属部分永久弯曲，将改变设备的 `reference_tare_counts`。这会使起始去皮值更接近极限，从而更有可能被违反。如果发生这种情况，你希望收到通知，因为你的硬件已永久损坏。

最后一种触发情况是温度变化。如果你的应变片被加热，它们的 `reference_tare_counts` 在环境温度和工作温度下可能有很大不同。在这种情况下，你可能需要增加 `force_safety_limit` 以适应热变化。

#### 称重传感器限位开关看门狗任务
在归位时，`load_cell_endstop` 会在 MCU 上启动一个任务来跟踪来自传感器的测量值。如果传感器在 2 个采样周期内未能发送测量值，看门狗将关闭打印机并报错 `!! 称重传感器限位开关等待 ADC 数据超时`。

如果发生这种情况，最可能的原因是 ADC 故障。打印机接地不良可能是根本原因。框架、电源外壳和打印热床都应连接到地。你可能需要在多个位置接地。阳极氧化铝型材导电性不好。你可能需要打磨接地线连接区域以确保良好的电气接触。

## 称重传感器探针设置

本节介绍称重传感器探针的调试过程。

### 首先验证称重传感器

`[load_cell_probe]` 也是一个 `[load_cell]`，与 `[load_cell]` 相关的 G-code 命令对 `[load_cell_probe]` 同样有效。在尝试使用称重传感器探针之前，请遵循使用 `CALIBRATE_LOAD_CELL` [校准称重传感器](Load_Cell.md#calibrating-a-load-cell) 并使用 `LOAD_CELL_DIAGNOSTIC` 检查其操作的说明。

### 使用 LOAD_CELL_TEST_TAP 验证探针操作

在实际尝试探测之前，使用 `LOAD_CELL_TEST_TAP` 命令测试称重传感器探针的操作。此命令检测轻敲，就像 `PROBE` 命令一样，但它不会移动 Z 轴。默认情况下，它在结束测试前会监听 3 次轻敲。你有 30 秒的时间完成每次轻敲，如果未检测到轻敲，命令将超时。

如果此测试失败，请仔细检查你的配置和 `LOAD_CELL_DIAGNOSTIC` 以查找问题。

称重传感器探针不支持 `QUERY_ENDSTOPS` 或 `QUERY_PROBE` 命令。在探测前使用 `LOAD_CELL_TEST_TAP` 测试功能。

### 归位宏

称重传感器探针不是限位开关，不支持 `endstop: probe:z_virtual_endstop`。目前，你需要将 Z 轴配置为使用 MCU 引脚作为其限位开关。你实际上不会使用该引脚，但目前必须配置某些内容。

要仅使用探针归位轴，你需要设置自定义归位宏。这需要设置 [homing_override](Config_Reference.md#homing_override)。

以下是一个可以实现此功能的简单宏。请注意，由于宏的工作方式，`_HOME_Z_FROM_LAST_PROBE` 宏必须是独立的。需要子调用，以便 `_HOME_Z_FROM_LAST_PROBE` 宏可以看到 `printer.probe.last_z_result` 中探测的结果。

```gcode
[gcode_macro _HOME_Z_FROM_LAST_PROBE]
gcode:
    {% set z_probed = printer.probe.last_z_result %}
    {% set z_position = printer.toolhead.position[2] %}
    {% set z_actual = z_position - z_probed %}
    SET_KINEMATIC_POSITION Z={z_actual}

[gcode_macro _HOME_Z]
gcode:
    SET_GCODE_OFFSET Z=0  # 称重传感器探针不需要 Z 偏移
    # 为归位 Z 定位喷头，根据你的打印机尺寸进行编辑
    #G90  # 绝对移动
    #G1 Y50 X50 F{5 * 60}  # 移动到归位的 X/Y 位置

    # 软归位 Z 轴到其极限，以便可以移动：
    SET_KINEMATIC_POSITION Z={printer.toolhead.axis_maximum[2]}

    # 快速接近并轻敲
    PROBE PROBE_SPEED={5 * 60}  # 覆盖速度以实现更快的归位
    _HOME_Z_FROM_LAST_PROBE

    # 将 Z 抬升至 2mm
    G91  # 相对移动
    G1 Z2 F{5 * 60}

    # 以标准速度探测
    PROBE
    _HOME_Z_FROM_LAST_PROBE

    # 将 Z 抬升至 10mm 以获得间隙
    G91  # 相对移动
    G1 Z10 F{5 * 60}
```

### 建议的探测温度

目前，我们建议在归位和探测时保持喷嘴温度低于导致耗材渗出的水平。140C 是一个很好的起点。这个温度也足够低，不会损坏 PEI 打印表面。

由于耗材渗出导致的喷嘴和打印热床污染是称重传感器探针探测误差的首要来源。Klipper 目前还没有通用的方法来检测由于耗材渗出导致的低质量轻敲。现有代码可能会将质量差的轻敲判断为有效。对这些低质量轻敲进行分类是当前活跃的研究领域。

Klipper 还缺乏支持，当探测位置因耗材渗出而污染时，无法重新定位探测点。像 `quad_gantry_level` 这样的模块会反复在相同坐标处探测，即使之前在此处探测失败。

鉴于上述情况，强烈建议不要在打印温度下进行探测。

### 热喷嘴保护

Voron 项目有一个很好的宏，用于保护你的打印表面免受热喷嘴的损害。参见 [Voron Tap 的 `activate_gcode`](https://github.com/VoronDesign/Voron-Tap/blob/main/config/tap_klipper_instructions.md)

强烈建议将类似内容添加到你的配置中。

### 喷嘴清洁

探测前喷嘴应清洁。你可以在每次打印前手动清洁。你也可以实现一个喷嘴清洁器并自动化该过程。以下是建议的顺序：

1. 等待喷嘴加热到探测温度（例如 `M109 S140`）
1. 归位机器（`G28`）
1. 在刷子上清洁喷嘴
1. 对打印热床进行热浸泡
1. 执行探测任务：QGL、床网等。

### 喷嘴热膨胀的温度补偿

如果你在安全温度下进行探测，喷嘴在加热到打印温度后会膨胀。这将导致喷嘴变长并更接近打印表面。你可以使用 [[z_thermal_adjust]](Config_Reference.md#z_thermal_adjust) 进行补偿。此调整将在从 PLA 到 PC 的一系列打印温度范围内有效。

#### 计算 `[z_thermal_adjust]` 的 `temp_coeff`

最简单的方法是在两个不同的温度下进行测量。理想情况下，这些温度应是打印温度范围的上限和下限。例如，180C 和 290C。你可以在两个温度下都执行 `PROBE_ACCURACY`，然后计算两者 `平均 z` 的差异。

调整值是喷嘴长度变化除以温度变化。例如：

```
temp_coeff = -0.05 / (290 - 180) = -0.00045455
```

预期结果为负数。`temp_coeff` 的正值使喷嘴更接近热床，负值使其远离热床。预计随着喷嘴变热而变长，需要将其移得更远。

#### 配置 `[z_thermal_adjust]`
设置 z_thermal_adjust 以 `extruder` 作为温度数据源。例如：

```
[z_thermal_adjust nozzle]
temp_coeff=-0.00045455
sensor_type: temperature_combined
sensor_list: extruder
combination_method: max
min_temp: 0
max_temp: 400
max_z_adjustment: 0.1
```

## 喷头称重传感器的连续去皮滤波器

Klipper 在 MCU 上实现了一个可配置的 IIR 滤波器，用于在探测时对称重传感器进行连续去皮。连续去皮意味着零值会随外部因素（如 Bowden 管和热变化）引起的漂移而移动。这主要针对在探测时经历大量变化外部力的喷头传感器和移动热床。

### 安装 SciPy

滤波代码使用优秀的 [SciPy](https://scipy.org/) 库，根据你在配置中输入的值计算滤波器系数。

为 32 位 Raspberry Pi 系统上的 Python 3 提供了预编译的 SciPy 构建。强烈建议使用 32 位 + Python 3，因为它将简化你的安装体验。它也可以与 Python 2 一起使用，但安装可能需要 30 多分钟并需要安装额外的工具。

```bash
~/klippy-env/bin/pip install scipy
```

### 滤波器工作台

滤波器参数应根据打印机在正常操作期间观察到的漂移来选择。在 scripts 中提供了一个 Jupyter 笔记本 [filter_workbench.ipynb](../scripts/filter_workbench.ipynb)，用于使用真实捕获的数据和 FFT 进行详细研究。

### 滤波建议

对于那些只是想让滤波器正常工作的人，请遵循以下建议：

* 唯一必需的选项是 `drift_filter_cutoff_frequency`。保守的起始值是 `0.5`Hz。Prusa 为 MK4 出厂设置为 `0.8`Hz，XL 为 `11.2`Hz。这可能是一个安全的实验范围。此值应仅增加到消除 Bowden 管力引起的正常漂移为止。将此值设置过高将导致触发缓慢和过多的力通过喷头。
* 保持 `trigger_force` 较低。默认值为 `75`g。漂移滤波器使内部克值非常接近 0，因此不需要大的触发力。
* 保持 `force_safety_limit` 为保守值。默认值为 2Kg，在实验期间应能保护你的喷头安全。如果你达到此限制，`drift_filter_cutoff_frequency` 值可能过高。

## 称重传感器工具板的建议

本节为开发希望支持 [load_cell_probe] 的喷头板的人员提供建议。

### ADC 传感器选择与板开发提示

理想情况下，传感器应满足以下标准：

* 至少 24 位宽
* 使用 SPI 通信
* 有一个引脚可用于在不使用 SPI 通信的情况下指示样本就绪。这通常称为“数据就绪”或“DRDY”引脚。检查引脚比运行 SPI 查询快得多。
* 具有 128 的可编程增益放大器增益设置。这应消除对外部放大器的需求。
* 通过 SPI 指示传感器是否已重置。检测重置可避免归位和启动时使用噪声数据时的时序错误。它还可以帮助用户追踪接线和接地问题。
* 在 350Hz 和 2Khz 之间可选择的采样率。非常高的采样率在我们的 3D 打印机中并不有益，因为它们在快速移动时会产生大量噪声。低于 250Hz 的采样率将需要更慢的探测速度。它们还会因测量之间的延迟更长而增加喷头上的力。例如，以 5mm/s 移动的 500Hz 传感器与以仅 1mm/s 移动的 100Hz 传感器具有相同的安全系数。
* 如果为床下应用设计，并且你想感应多个称重传感器，请使用可以同时采样所有输入的芯片。需要切换通道的多路复用 ADC 在每次通道切换后需要几个样本的稳定时间，因此不适合探测应用。

使用 Klipper 的 `bulk_sensor` 和 `load_cell_endstop` 基础设施实现对新传感器芯片的支持并不特别困难。

### 5V 电源滤波

强烈建议使用比 ADC 芯片制造商规定的更大的电容器。ADC 芯片通常针对低噪声环境（如电池供电设备）设计。传感器制造商建议的应用说明通常假设电源安静。将他们建议的电容值视为最小值。

3D 打印机在 5V 总线上产生大量噪声，这会破坏传感器的准确性。在决定平滑电容器大小之前，请在典型 3D 打印机电源和活动步进驱动器下测试板上的传感器。

### 接地与接地平面

模拟 ADC 芯片包含对噪声和 ESD 非常敏感的组件。在芯片下方的第一层板上设置大面积接地平面有助于降低噪声。将芯片远离电源部分和 DC 到 DC 转换器。板子应正确接地回 DC 电源。

### HX711 和 HX717 说明

此传感器因其低成本和供应链中的可用性而受欢迎。然而，此传感器存在一些缺点：

* HX71x 传感器使用位脉冲通信，对 MCU 有很高的开销。使用通过 SPI 通信的传感器将节省工具板 CPU 上的资源。
* HX71x 缺乏向 MCU 通信重置事件的方式。Klipper 使用时序启发式方法检测重置，但这并不理想。重置表明接线或接地存在问题。
* 对于探测应用，强烈推荐 HX717 版本，因为其采样率更高（320 对 80）。HX711 上的探测速度应限制在小于 2mm/s。
* HX71x 上的采样率无法从 Klipper 的配置中设置。如果你有 10SPS 版本的传感器（广泛分发），则需要物理重新布线以在 80SPS 下运行。
