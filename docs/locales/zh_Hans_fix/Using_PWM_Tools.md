# 使用PWM工具

文档描述了如何使用`pwm_tool`和一些宏来设置PWM控制的激光或主轴。以下是如何操作的概述：

### 工作原理

通过重新定义打印头风扇的PWM输出，您可以控制激光或主轴。这对于使用可切换打印头的情况非常有用，例如E3D工具更换器或DIY解决方案。通常，像LaserWeb这样的CAM工具可以配置为使用`M3-M5`命令，这些命令分别代表顺时针主轴速度（`M3 S[0-255]`）、逆时针主轴速度（`M4 S[0-255]`）和主轴停止（`M5`）。

**警告：** 当驱动激光时，请采取所有你能想到的安全预防措施！二极管激光通常是反相的，这意味着当微控制器单元（MCU）重启时，激光会在MCU重新启动期间完全开启。因此，建议在激光供电时总是佩戴适当波长的护目镜，并且在不需要时断开激光连接。此外，你应该配置一个安全超时，这样当主机或MCU遇到错误时，工具会停止。

### 命令

- `M3/M4 S<value>`：设置PWM占空比。值介于0到255之间。
- `M5`：停止PWM输出至关闭值。

### LaserWeb配置

如果使用LaserWeb，一个有效的配置如下：

开始GCODE:
```gcode
M5            ; 禁用激光
G21           ; 设置单位为毫米
G90           ; 绝对定位
G0 Z0 F7000   ; 设置非切割速度
```

结束GCODE:
```gcode
M5            ; 禁用激光
G91           ; 相对定位
G0 Z+20 F4000 ;
G90           ; 绝对定位
```

归位GCODE:
```gcode
M5            ; 禁用激光
G28           ; 归位所有轴
```

工具开：
```gcode
M3 $INTENSITY ; 根据强度开启激光
```

工具关：
```gcode
M5            ; 禁用激光
```

激光强度由`S`参数决定，该参数需要在`M3`命令中指定其值来调整激光的强度。例如，`M3 S128`将设置激光强度到中间值。请根据具体需求进行相应调整。记得在任何情况下都要遵守安全指南以避免意外发生。
